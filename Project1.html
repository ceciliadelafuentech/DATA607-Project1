Overview

For Project 1, I started by examining the tournament results in the text file. The file contains unstructured data. My plan is to extract the player information, including Player’s Name, Player’s State, Total Number of Points, and Player’s Pre-Rating. Then, using the opponent numbers listed for each player, identify who they played and match those players to their pre-tournament ratings. I will use this information to calculate the average pre-rating of each player’s opponents and combine everything into a data frame that can be exported as a CSV file.

I then calculated the average pre-rating of the opponents for every player. For each player, I matched their opponent pair numbers to the corresponding pre-ratings and calculated the mean. I used na.rm = TRUE so that missing values would not affect the calculation.

avg_opponent_rating <- sapply(opponents, function(x) {
  ratings <- players$pre_rating[match(x, players$pair)]

Conclusion

My approach to this project was to break the text file piece by piece and extract one column at a time, starting with the player names. Once I figured out how the information was structured, I used the same approach to extract the state, total points, pre-rating, and opponent numbers. I then used the opponent numbers to match each player with their opponents’ pre-ratings and calculate the average.

I had learned about regular expressions before, but I did not expect to use them in this project. They ended up being helpful for identifying the lines I needed from the text file and extracting the information. I also learned new functions that allow to perform the same transformation for multiple lines in the file. This made it easier to turn the unstructured text file into a data frame and then export it as a CSV file.
